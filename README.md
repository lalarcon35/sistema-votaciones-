# Sistema de Votación - Festival de la Leyenda Vallenata

Plataforma web desarrollada en Django para la gestión y votación segura de participantes en el Festival de la Leyenda Vallenata.

## 🚀 Tecnologías utilizadas
* **Backend:** Python 3.11, Django 5.2
* **Base de Datos:** MySQL / MySQL Workbench
* **Frontend:** HTML5, CSS3, JavaScript
* **Librería de Alertas:** SweetAlert2

## 📋 Requisitos previos
Asegúrate de tener instalado en tu equipo:
* Python (versión 3.11 o superior)
* Git
* MySQL
